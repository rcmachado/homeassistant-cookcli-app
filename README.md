# CookCLI Home Assistant App

This repository contains a set of Home Assistant apps (formely add-ons) for CookCLI app.

## Installation

1. Go to the Add-on Store → Click the **More** button (⋮) in the upper-right corner → Select **Repositories**  
2. Paste the following URL:  
   [https://github.com/rcmachado/homeassistant-cookcli-app](https://github.com/rcmachado/homeassistant-cookcli-app)
3. Or, simply click the button below to add it automatically:

[![Add Repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Frcmachado%2Fhomeassistant-cookcli-app)
